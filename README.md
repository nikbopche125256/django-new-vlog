Django New Vlog

Django New Vlog is a simple web application built using the Django framework. It is designed to manage and display vlog/blog-style posts in a structured and dynamic way. This project helps in understanding core Django concepts such as models, views, templates, and URL routing.

🚀 Features
Create and manage vlog/blog posts
Dynamic content rendering using Django templates
Admin panel for easy content management
Clean and simple project structure
Built using Django MVC architecture
🛠️ Tech Stack
Python
Django
SQLite (default database)
HTML, CSS (for frontend templates)
📁 Project Structure
manage.py → Main file to run Django commands
settings.py → Project configuration (database, apps, templates, etc.)
urls.py → URL routing for the project
models.py → Database structure for vlog/blog posts
views.py → Logic for handling requests and responses
templates/ → HTML files for UI rendering
static/ → CSS, JS, images (if used)
admin.py → Django admin configuration
migrations/ → Database migration files
⚙️ Installation & Setup
Clone the repository:
git clone https://github.com/nikbopche125256/django-new-vlog.git
Move into project directory:
cd django-new-vlog
Create virtual environment:
python -m venv venv
Activate virtual environment:
venv\Scripts\activate   # Windows
source venv/bin/activate  # Mac/Linux
Install dependencies:
pip install -r requirements.txt
Run migrations:
python manage.py migrate
Start development server:
python manage.py runserver
📌 Purpose of Project

This project is built for learning and practicing Django backend development.
It helps in understanding how a real-world web application is structured using Django.
